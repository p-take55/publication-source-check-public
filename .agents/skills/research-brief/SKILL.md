# 調査を提案資料にまとめる

1. 調べるテーマ、読者、判断したいことを確認する。
2. 一次情報を優先し、出典と確認日を記録する。
3. 依頼者から示された読み手と前提条件（予算・期限など）に沿って選択肢を比較する。前提が示されていなければ確認し、推測で埋めない。
4. 要点、根拠、次のアクションを `knowledge/report-format.md` に合わせて書く。
5. 不確かな記述に断定がないか確認する。
